⚠️ Lose resources if unprepared.

Ingredient Shortage
"We’re out of taro!"
✅ A random ingredient type is banned for the round (e.g., powders, toppings).

Machine Breakdown

✅ One key station cannot be used this round unless repaired.

Boba Delivery Delay

"Your latest post went viral!"
✅ +1 point for each drink that includes a color or visual topping (e.g., jelly, foam, glitter).

Seasonal Menu Rotation
"Out with the old, in with the fresh."
✅ Only fruit teas and specials can be played. Milk teas are temporarily banned.

Loyal Customer Parade

Happy Hour
"Half-off drinks = twice the customers."
